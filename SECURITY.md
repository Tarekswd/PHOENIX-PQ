# Security and Disclosure Policy

## Findings in third-party code

This project audits third-party post-quantum implementations (currently HQC).

- New, unfixed findings are reported privately to the affected maintainers first.
- Raw results (`experiments/**/results/`) are excluded from this repository until the maintainers have had reasonable time to respond (default: 90 days, or earlier if they publish a fix).
- Issues the maintainers already track publicly (for example HQC work item #11) may be discussed openly.

## Code in this repository

Nothing here is production-ready, and nothing here is claimed secure. The harnesses and scripts are research tooling.

To report a problem with this repository's own code, open a GitHub issue. If the report is sensitive, contact the maintainer privately through GitHub first.
